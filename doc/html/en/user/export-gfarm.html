Accessing the Gfarm File System by Using Other Protocols

English | Japanese

1. Overview

We investigated whether the Gfarm file system can be exported via file sharing and publishing server applications. It can be achieved by combining each server with gfarm2fs.

Linked entries have detailed descriptions. Please apply these to other servers as well.

  • A: tested
  • B: only a simple operation check
  • N: impossible
  • "allow_root required" means that the file system needs to be mounted with the -o allow_root option of FUSE. For details, see the README of the FUSE package.
