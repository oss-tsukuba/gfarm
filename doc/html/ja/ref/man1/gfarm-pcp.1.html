Name

gfarm-pcp — 複数のホストにファイルをコピーする

Synopsis

gfarm-pcp [オプション] コピー元 コピー先

gfarm-pcp [オプション] コピー元... ディレクトリ

DESCRIPTION

gfarm-pcp は、ローカルの コピー元のファイルを、 ホストファイルに記述された各ホストのコピー先 あるいはディレクトリに、 リモートコピーコマンド (デフォルトは scp -pr) を用いてコピーします。コピー先の相対パスは、 リモートホストのホームディレクトリからの相対パスとなります。 Gfarm のファイルシステムノードへの設定ファイルの配布などに利用できます。

デフォルトでは、一つのホストずつ順番にファイルをコピーします。 -p オプションを指定すると、複数のホストに並列にファイルをコピーします。

ホストファイルの形式と、ローカルホストを除外する方法は gfarm-prun と同じです。 gfarm-prun(1) を参照してください。

環境変数 PRUN_RCP に no を設定すると、 リモートコピーコマンドを用いず、 環境変数 PRUN_RSH で指定するリモートシェルコマンドを用いてファイルをコピーします。この場合、 最後の引数はリモートホスト上のディレクトリである必要があり、 コピーできるのは通常ファイルだけです。また、 ファイルのパーミッションは保存されません。

OPTIONS

-a

ホストファイルにローカルホストが含まれている場合、 ローカルホストにもファイルをコピーします。

-h ホストファイル

ホストファイルを指定します。`-' を指定すると、 ホストの一覧を標準入力から読み込みます。

-m 最大ジョブ数

-p オプションを指定したときに、 並列にファイルをコピーするホストの最大数を指定します。デフォルトは 16 です。

-n

実行するコマンドを表示しますが、実行はしません。

-p

バックグラウンドで、複数のホストに並列にファイルをコピーします。

-rcp リモートコピーコマンド

リモートコピーコマンドを指定します。デフォルトは scp -pr です。no を指定すると、 上記のようにリモートシェルコマンドを用いてファイルをコピーします。

-v

各ホストにファイルをコピーする前に、ホスト名を表示します。 -p オプションを指定した場合は、このオプションは効果がありません。

ENVIRONMENT VARIABLES

PRUN_RCP

リモートコピーコマンドを指定します。デフォルトは scp -pr です。

PRUN_RSH

PRUN_RCP が no の場合に利用するリモートシェルコマンドを指定します。デフォルトは ssh です。

PRUN_HOSTFILE, PRUN_HOSTNAME, PRUN_MAX_JOBS, PRUN_PARALLEL, PRUN_ALL_INCLUDE_MYSELF, PRUN_VERBOSE

gfarm-prun と同じです。 gfarm-prun(1) を参照してください。

EXIT STATUS

全てのホストへのコピーが成功した場合、 gfarm-pcp は 0 で終了します。 そうでない場合、コピーが失敗したホストについて、 コピーコマンドの終了ステータスで終了します。 複数のホストで失敗した場合は、 そのうちの一つのホストに対する終了ステータスを返します。

EXAMPLES

gfarm2.conf を、 $HOME/.nodelist に記述された、 ローカルホスト以外の全てのホストの /tmp にコピーします。


$ gfarm-pcp gfarm2.conf /tmp

ユーザの共有鍵を、 hosts に記述された全てのホストのホームディレクトリに、並列にコピーします。


$ gfarm-pcp -p -h hosts .gfarm_shared_key .

FILES

$HOME/.nodelist

デフォルトのホストファイル
