GSI Authentication

English | Japanese

This document describes the settings required for GSI authentication in Gfarm. For details, refer to the GSI C Admin Guide.

Certificate Authority

The certificates of trusted certificate authorities are stored in /etc/grid-security/certificates in the form of HASH.0. A signing policy file (HASH.signing_policy) is also required.

Host certificate

gfmd requires a host certificate, which is stored in /etc/grid-security/host{cert,key}.pem by default. The location can be changed by the X509_USER_{CERT,KEY} environment variables.

Gfsd service certificate

gfsd requires a gfsd service certificate, which is stored in /etc/grid-security/gfsd/gfsd{cert,key}.pem by default. When gfsd is configured with the -l option of config-gfsd, the directory is /etc/grid-security/gfsd-LISTEN_ADDRESS instead. The location can be changed by the X509_USER_{CERT,KEY} environment variables. These files should be owned by the _gfarmfs user.

User certificate

Each user requires a user certificate, which is stored in $HOME/.globus/user{cert,key}.pem by default. The location can be changed by the X509_USER_{CERT,KEY} environment variables.

In GSI, a proxy certificate can be generated by the grid-proxy-init or proxy-cert-gen command. The default location is /tmp/x509up_u${UID}. The location can be changed by the X509_USER_PROXY environment variable.
