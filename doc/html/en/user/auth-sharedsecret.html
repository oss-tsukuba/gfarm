Shared Secret Authentication

English | Japanese

This document describes the settings required for shared secret authentication in Gfarm.

Shared secret key

A shared secret key must be created for each user and distributed to all hosts. The default path is .gfarm_shared_key in the home directory. The location can be changed by the shared_key_file directive in the Gfarm configuration file.

A shared secret key is created with the gfkey command. 

$ gfkey -f -p 31536000
This creates a shared secret key valid for 31536000 seconds (= 365 days). This key needs to be distributed to all hosts at the same location with the same owner and permissions. The key must also be regenerated and redistributed before it expires.

Shared secret authentication can also be used by gfsd and gfmd. The shared secret key for gfsd should be generated for the _gfarmfs user and distributed to all gfsd and gfmd hosts. The shared secret key for gfmd should be generated for the _gfarmmd user and distributed to all gfmd hosts.
