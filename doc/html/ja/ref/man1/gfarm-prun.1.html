Name

gfarm-prun — 複数のホストでコマンドを実行する

Synopsis

gfarm-prun [オプション] コマンド [引数...]

DESCRIPTION

gfarm-prun は、 ホストファイルに記述された各ホストで、 コマンド を引数とともに、 リモートシェルコマンド (デフォルトは ssh) を用いて実行します。Gfarm のファイルシステムノードの設定や管理などに利用できます。

デフォルトでは、一つのホストずつ順番にコマンドを実行します。 -p オプションを指定すると、複数のホストで並列にコマンドを実行します。

ホストファイルには、一行に一つのホスト名を記述します。 各行の最初のフィールドだけが利用されます。 `#' から行末まではコメントとみなされ、空行は無視されます。 デフォルトのホストファイルは $HOME/.nodelist です。

-a オプションを指定しない場合、 ローカルホストではコマンドを実行しません。 hostname の出力、あるいは hostname -I で表示される IP アドレスのいずれかに一致するホストを、ローカルホストとみなします。 node1 と node1.example.com のように、一方だけにドメイン部がある場合も一致しますが、 node1 と node10 は一致しません。 これらの名前は環境変数 PRUN_HOSTNAME で変更できます。

コマンドラインはリモートシェルコマンドに渡され、 リモートホスト上のシェルで解釈されます。コマンドライン中のワイルドカードは、 ローカルホストではなくリモートホストで展開されます。

-stdin オプションを指定しない場合、 リモートで実行するコマンドの標準入力は /dev/null となります。

OPTIONS

-a

ホストファイルにローカルホストが含まれている場合、 ローカルホストでもコマンドを実行します。

-h ホストファイル

ホストファイルを指定します。`-' を指定すると、 ホストの一覧を標準入力から読み込みます。

-m 最大ジョブ数

-p オプションを指定したときに、 並列にコマンドを実行するホストの最大数を指定します。デフォルトは 16 です。

-n

実行するコマンドを表示しますが、実行はしません。

-p

バックグラウンドで、複数のホストで並列にコマンドを実行します。

-rsh リモートシェルコマンド

リモートシェルコマンドを指定します。デフォルトは ssh です。

-stdin ファイル

各ホストで実行するコマンドの標準入力に与えるファイルを指定します。 このオプションは複数回指定でき、 その場合はファイルを連結したものが標準入力となります。`-' を指定すると、 gfarm-prun の標準入力を一度読み込み、各ホストのコマンドに与えます。-h オプションと -stdin オプションの両方に `-' を指定することはできません。

-v

各ホストでコマンドを実行する前に、ホスト名を表示します。 -p オプションを指定した場合は、このオプションは効果がありません。

ENVIRONMENT VARIABLES

PRUN_RSH

リモートシェルコマンドを指定します。デフォルトは ssh です。

PRUN_HOSTFILE

ホストファイルを指定します。デフォルトは $HOME/.nodelist です。

PRUN_HOSTNAME

ローカルホストの名前を空白区切りで指定します。デフォルトは hostname と hostname -I の出力です。

PRUN_MAX_JOBS

並列に実行するジョブの最大数を指定します。デフォルトは 16 です。

PRUN_PARALLEL

yes を設定すると、 -p オプションと同様に並列にコマンドを実行します。

PRUN_ALL_INCLUDE_MYSELF

yes を設定すると、 -a オプションと同様にローカルホストでもコマンドを実行します。

PRUN_VERBOSE

yes を設定すると、 -v オプションと同様にホスト名を表示します。

EXIT STATUS

全てのホストでコマンドが成功した場合、 gfarm-prun は 0 で終了します。 そうでない場合、コマンドが失敗したホストについて、 リモートシェルコマンドの終了ステータスで終了します。 複数のホストで失敗した場合は、 そのうちの一つのホストに対する終了ステータスを返します。

EXAMPLES

$HOME/.nodelist に記述された、 ローカルホスト以外の全てのホストの稼働時間を表示します。


$ gfarm-prun -v uptime

hosts に記述された全てのホストで、並列に gfsd を再起動します。


$ gfarm-prun -p -h hosts sudo systemctl restart gfsd

ローカルのシェルスクリプト setup.sh を各ホストで実行します。


$ gfarm-prun -h hosts -stdin setup.sh sh

FILES

$HOME/.nodelist

デフォルトのホストファイル
