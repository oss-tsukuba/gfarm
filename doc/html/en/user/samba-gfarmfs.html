Mount Gfarm File System from Windows Machines

English | Japanese

1. Summary

Windows clients can access the Gfarm file system using gfarm2fs and Samba.

Configuration

  • Samba (Linux) machine
    • Install Gfarm and gfarm2fs. Shared secret authentication is recommended.
    • Install FUSE, and specify 'user_allow_other' in /etc/fuse.conf.
    • Install Samba server (smbd).
Software
  • Gfarm and gfarm2fs: http://oss-tsukuba.org/en/software/gfarm
  • FUSE: https://github.com/libfuse/libfuse
  • Samba: https://www.samba.org/

2. Japanese Filename

See Samba in Japanese

3. Samba Configuration - smb.conf

Specify the mount point of the Gfarm file system in [homes] or [Section Name].
When each user mounts the Gfarm file system on /tmp/gfarm/username, the following configuration exports the mount point via Samba: 
[Gfarm]
path = /tmp/gfarm/%u
create mask = 0644
read only = no

See the Samba documentation for details of the Samba configuration.

4. FUSE Configuration

FUSE 2.3.0 or later requires the following setting.

/etc/fuse.conf 
user_allow_other

This allows users to specify the -o allow_root or -o allow_other option.

5. Mount by Gfarm2fs

First, check whether you can access Gfarm with 'gfdf' and 'gfhost -l'. If successful, mount the Gfarm file system by 'gfarm2fs' on the Samba server. 

  $ gfarm2fs [gfarm2fs options] mountpoint -o allow_root [FUSE options]

This mount point must be exported by Samba (see section 3).

Attention

Do not specify '-o allow_other' for the FUSE options. It allows all users to access the Gfarm file system using *your* privilege.

6. Example of Samba Configuration and Application

In this example, the Gfarm file system is automatically mounted by gfarm2fs when you connect to the 'Gfarm' shared folder. This assumes that the ~/samba-fuse directory exists. The preexec script mounts the Gfarm file system on ~/samba-fuse automatically, and the postexec script unmounts it.

This also assumes that the shared secret key is distributed correctly, or a valid proxy certificate exists on the Samba machine. 

[Gfarm]
  path = %H/samba-fuse
  preexec = /usr/local/bin/gfarmfsmount.sh %P
  preexec close = Yes
  postexec = /usr/local/bin/gfarmfsumount.sh %P
  read only = no

gfarmfsmount.sh 
#! /bin/sh

GFARMFS=/usr/local/bin/gfarm2fs
USERNAME=`/usr/bin/whoami`
LOGFILE=/tmp/gfarm2fs-$USERNAME.log

ALLOWROOT="-o allow_root"

GREP=/bin/grep
DF=/bin/df
TAIL=/usr/bin/tail
DATE=/bin/date

# for fusermount
export PATH=$PATH:/usr/local/bin

#####
if [ $# -ne 1 ]; then
    echo "usage: `basename $0` MOUNTPOINT"
    exit 1
fi

if [ ! -f $LOGFILE ]; then
    touch $LOGFILE
    chmod 600 $LOGFILE
fi

DATE=`$DATE '+%Y%m%d-%H%M%S'`
MOUNTP=$1

($DF -t fuse.gfarm2fs $MOUNTP | $TAIL -n +2 | $GREP gfarm2fs > /dev/null && \
    (echo $DATE MOUNT:ALREADY $MOUNTP) || \
    ($GFARMFS $MOUNTP $ALLOWROOT && \
    echo $DATE MOUNT:SUCCESS $MOUNTP || ! echo $DATE MOUNT:FAIL $MOUNTP)
) >> $LOGFILE 2>&1

exit $?

gfarmfsumount.sh 
#! /bin/sh

# use fusermount instead of fusermount3 for FUSE 2
FUSERMOUNT=/usr/bin/fusermount3

USERNAME=`/usr/bin/whoami`
LOGFILE=/tmp/gfarm2fs-$USERNAME.log

DATE=/bin/date
SLEEP=/bin/sleep

#####
if [ $# -ne 1 ]; then
    echo "usage: `basename $0` MOUNTPOINT"
    exit 1
fi

if [ ! -f $LOGFILE ]; then
    touch $LOGFILE
    chmod 600 $LOGFILE
fi

DATE=`date '+%Y%m%d-%H%M%S'`
MOUNTP=$1

(cd /; $SLEEP 1;
    $FUSERMOUNT -u $MOUNTP && \
        echo $DATE UMOUNT:SUCCESS $MOUNTP || \
        echo $DATE UMOUNT:FAIL $MOUNTP
) >> $LOGFILE 2>&1 &
