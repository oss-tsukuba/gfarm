Name

gfarm-prun — execute a command on multiple hosts

Synopsis

gfarm-prun [options] command [arg...]

DESCRIPTION

gfarm-prun executes command with args on each host listed in a hostfile, by using a remote shell command, ssh by default. It is useful, for example, to set up or manage filesystem nodes of Gfarm.

By default, the command is executed on one host after another. When the -p option is specified, the command is executed on multiple hosts in parallel.

The hostfile has one host name in each line. Only the first field of each line is used. Characters from `#' to the end of the line are regarded as a comment, and empty lines are ignored. The default hostfile is $HOME/.nodelist.

The local host is skipped unless the -a option is specified. A host is regarded as the local host when its name matches the output of hostname or one of the IP addresses displayed by hostname -I. A host name also matches when only one of them has the domain part, for example, node1 and node1.example.com, but node1 does not match node10. These names can be changed by the PRUN_HOSTNAME environment variable.

The command line is passed to the remote shell command, thus it is interpreted by a shell on the remote host. Wildcards in the command line are expanded on the remote host, not on the local host.

Unless the -stdin option is specified, the standard input of the remote command is /dev/null.

OPTIONS

-a

Executes the command also on the local host, if it is listed in the hostfile.

-h hostfile

Specifies a hostfile. If `-' is specified, the list of hosts is read from the standard input.

-m max_jobs

Specifies the maximum number of hosts on which the command is executed in parallel with the -p option. The default is 16.

-n

Displays the commands that would be executed, but does not execute them.

-p

Executes the command on multiple hosts in parallel in the background.

-rsh rsh_command

Specifies a remote shell command. The default is ssh.

-stdin file

Specifies a file that is given to the standard input of the command on each host. This option can be specified multiple times. In this case, the files are concatenated. If `-' is specified, the standard input of gfarm-prun is read once, and it is given to the command on each host. `-' cannot be specified for both the -h option and the -stdin option.

-v

Displays the host name before executing the command on the host. This option has no effect with the -p option.

ENVIRONMENT VARIABLES

PRUN_RSH

Specifies a remote shell command. The default is ssh.

PRUN_HOSTFILE

Specifies a hostfile. The default is $HOME/.nodelist.

PRUN_HOSTNAME

Specifies the names of the local host, separated by spaces. The default is the output of hostname and hostname -I.

PRUN_MAX_JOBS

Specifies the maximum number of parallel jobs. The default is 16.

PRUN_PARALLEL

If it is set to yes, the command is executed in parallel as with the -p option.

PRUN_ALL_INCLUDE_MYSELF

If it is set to yes, the command is executed also on the local host as with the -a option.

PRUN_VERBOSE

If it is set to yes, the host name is displayed as with the -v option.

EXIT STATUS

gfarm-prun exits with 0 when the command succeeds on all hosts. Otherwise, it exits with the exit status of the remote shell command for a host on which the command fails. When it fails on two or more hosts, the exit status for one of them is returned.

EXAMPLES

Displays the uptime of all hosts listed in $HOME/.nodelist, except the local host.


$ gfarm-prun -v uptime

Restarts gfsd on all hosts listed in hosts, in parallel.


$ gfarm-prun -p -h hosts sudo systemctl restart gfsd

Executes a local shell script setup.sh on each host.


$ gfarm-prun -h hosts -stdin setup.sh sh

FILES

$HOME/.nodelist

the default hostfile
