Name

gfarm-pcp — copy files to multiple hosts

Synopsis

gfarm-pcp [options] source destination

gfarm-pcp [options] source... directory

DESCRIPTION

gfarm-pcp copies local files source to destination or directory on each host listed in a hostfile, by using a remote copy command, scp -pr by default. A relative path of the destination is relative to the home directory on the remote host. It is useful, for example, to distribute configuration files to filesystem nodes of Gfarm.

By default, files are copied to one host after another. When the -p option is specified, files are copied to multiple hosts in parallel.

The format of the hostfile, and how the local host is skipped, are the same as gfarm-prun. See gfarm-prun(1).

When the PRUN_RCP environment variable is set to no, files are copied by the remote shell command specified by the PRUN_RSH environment variable, without a remote copy command. In this case, the last argument must be a directory on the remote host, and only regular files can be copied. The permission of the files is not preserved.

OPTIONS

-a

Copies files also to the local host, if it is listed in the hostfile.

-h hostfile

Specifies a hostfile. If `-' is specified, the list of hosts is read from the standard input.

-m max_jobs

Specifies the maximum number of hosts to which files are copied in parallel with the -p option. The default is 16.

-n

Displays the commands that would be executed, but does not execute them.

-p

Copies files to multiple hosts in parallel in the background.

-rcp rcp_command

Specifies a remote copy command. The default is scp -pr. If no is specified, files are copied by the remote shell command as described above.

-v

Displays the host name before copying files to the host. This option has no effect with the -p option.

ENVIRONMENT VARIABLES

PRUN_RCP

Specifies a remote copy command. The default is scp -pr.

PRUN_RSH

Specifies a remote shell command that is used when PRUN_RCP is no. The default is ssh.

PRUN_HOSTFILE, PRUN_HOSTNAME, PRUN_MAX_JOBS, PRUN_PARALLEL, PRUN_ALL_INCLUDE_MYSELF, PRUN_VERBOSE

The same as gfarm-prun. See gfarm-prun(1).

EXIT STATUS

gfarm-pcp exits with 0 when files are copied to all hosts successfully. Otherwise, it exits with the exit status of the copy command for a host to which the copy fails. When it fails for two or more hosts, the exit status for one of them is returned.

EXAMPLES

Copies gfarm2.conf to /tmp on all hosts listed in $HOME/.nodelist, except the local host.


$ gfarm-pcp gfarm2.conf /tmp

Copies the shared secret key of the user to the home directory on all hosts listed in hosts, in parallel.


$ gfarm-pcp -p -h hosts .gfarm_shared_key .

FILES

$HOME/.nodelist

the default hostfile
